# Issue specifications

C00–C10 and K01 are the initial issue body snapshots. GitHub issues are the live work and verification record; docs/ROADMAP.md and docs/issue-index.json map stable task IDs to actual issue numbers. The product/architecture/format/testing documents define shared requirements; avoid divergent copies of those requirements in issues.

Update the repository specification if requirements change, and link that change in the affected live issue.
