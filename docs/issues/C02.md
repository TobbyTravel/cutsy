## Problem
Legacy descriptions, generic anchors and fixed-grid crops cannot support a polished runtime pack yet.

## Expected behavior and implementation boundaries
Inspect all 80 frames and source sheets; correct labels/direction/crops; examine alpha on contrasting backgrounds; measure scale and contact anchors; author body masks; retain original files and derivation metadata; generate visual review previews.

## Dependencies
[C01](https://github.com/TobbyTravel/cutsy/issues/2)

## Acceptance checklist
- [ ] Every frame has used/superseded/excluded status
- [ ] suspected clipped frames individually resolved
- [ ] no unexplained background rectangle/halo or neighbor fragment in shipped frames
- [ ] anchors and masks reviewed
- [ ] immutable source hashes still pass.

## Required verification
Follow [TESTING.md](https://github.com/TobbyTravel/cutsy/blob/main/docs/TESTING.md), selecting the scenarios applicable to this issue. Add automated tests for deterministic core/validation behavior and manual evidence for desktop behavior. Record commit, pack hash when relevant, commands, observed results and untested scenarios. Do not close merely because the code builds.
