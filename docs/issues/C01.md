## Problem
Create the buildable skeleton needed by the implementation issues.

## Expected behavior and implementation boundaries
Create net10.0 Cutsy.Core, net10.0-windows Cutsy.Windows, Cutsy.PackTool, and an xUnit core test project; pin a stable .NET 10 SDK; add build/test PowerShell scripts and Windows GitHub Actions CI with least permissions; keep binary output out of Git.

## Dependencies
No prerequisites.

## Acceptance checklist
- [ ] Clean checkout restores and builds
- [ ] tests exercise actual core behavior as it arrives
- [ ] CI reports real outcomes
- [ ] scripts documented and executable
- [ ] host remains distinct from portable core.

## Required verification
Follow [TESTING.md](https://github.com/TobbyTravel/cutsy/blob/main/docs/TESTING.md), selecting the scenarios applicable to this issue. Add automated tests for deterministic core/validation behavior and manual evidence for desktop behavior. Record commit, pack hash when relevant, commands, observed results and untested scenarios. Do not close merely because the code builds.
