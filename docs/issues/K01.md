## Problem
Determine how a later KDE host can position a mascot and observe native Wayland windows.

## Expected behavior and implementation boundaries
Research and prototype KWin integration/IPC for geometry, exposure, overlay placement, input and fullscreen; evaluate required permissions and distro/Plasma versions; reuse core capability contracts; distinguish X11/XWayland/native Wayland.

## Dependencies
Deferred; not part of the Windows milestone.

## Acceptance checklist
- [ ] Evidence-backed feasibility note and bounded prototype plan
- [ ] unsupported capabilities and packaging costs recorded
- [ ] no claims of a shipped Linux port
- [ ] does not block Windows milestone.
