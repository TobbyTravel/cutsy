## Problem
Mascot and audio must get out of the way during games and presentations.

## Expected behavior and implementation boundaries
Combine foreground geometry and notification state with 500 ms checks and foreground events; hide on all monitors for fullscreen/presentation/lock, manual Gaming mode and app exclusions; stop audio and cancel drag; resume after 3 seconds continuously eligible; expose state/reason for settings.

## Dependencies
[C03](https://github.com/TobbyTravel/cutsy/issues/4), [C04](https://github.com/TobbyTravel/cutsy/issues/5)

## Acceptance checklist
- [ ] Fullscreen video/borderless/presentation/lock/manual/exclusion paths verified where available
- [ ] maximized ordinary windows handled
- [ ] no mid-drag stuck capture
- [ ] stable resume
- [ ] API errors degrade safely
- [ ] no injection/game-memory access or unsupported anti-cheat claim.

## Required verification
Follow [TESTING.md](https://github.com/TobbyTravel/cutsy/blob/main/docs/TESTING.md), selecting the scenarios applicable to this issue. Add automated tests for deterministic core/validation behavior and manual evidence for desktop behavior. Record commit, pack hash when relevant, commands, observed results and untested scenarios. Do not close merely because the code builds.
