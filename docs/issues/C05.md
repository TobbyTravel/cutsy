## Problem
Mascot needs real exposed support edges and stable contacts when application windows change.

## Expected behavior and implementation boundaries
Enumerate/filter windows; add out-of-context events and bounded reconciliation; calculate z-order exposed segments; implement perch/sit/hang/peek/jump/fall support transitions; clip peeks; exclude caption controls when feasible; recover when support disappears.

## Dependencies
[C03](https://github.com/TobbyTravel/cutsy/issues/4), [C04](https://github.com/TobbyTravel/cutsy/issues/5)

## Acceptance checklist
- [ ] Move/resize/minimize/close/occlusion and virtual desktop changes tested
- [ ] no perch without headroom
- [ ] contacts stable
- [ ] monitor removal recovers
- [ ] handles remain host-only
- [ ] shell and mascot excluded.

## Required verification
Follow [TESTING.md](https://github.com/TobbyTravel/cutsy/blob/main/docs/TESTING.md), selecting the scenarios applicable to this issue. Add automated tests for deterministic core/validation behavior and manual evidence for desktop behavior. Record commit, pack hash when relevant, commands, observed results and untested scenarios. Do not close merely because the code builds.
