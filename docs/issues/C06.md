## Problem
The release needs complete recipes using most usable artwork rather than a demonstration loop.

## Expected behavior and implementation boundaries
Author compatible idle, expression, directional walk/run, jump/fall/recover, edge sit/hang/peek, phone/boba/laptop/cleaning/carry/plush, sleep/wake and click/pickup/drop sequences; implement calm weights, cooldowns, grace and Stay here; add validated authoring examples.

## Dependencies
[C02](https://github.com/TobbyTravel/cutsy/issues/3), [C04](https://github.com/TobbyTravel/cutsy/issues/5), [C05](https://github.com/TobbyTravel/cutsy/issues/6)

## Acceptance checklist
- [ ] Target at least 64 usable source frames with all 80 accounted for
- [ ] no opposite-direction walk cycle or prop morphing
- [ ] every recipe validates
- [ ] fixed-contact previews inspected at display size
- [ ] excluded art has explicit reason.

## Required verification
Follow [TESTING.md](https://github.com/TobbyTravel/cutsy/blob/main/docs/TESTING.md), selecting the scenarios applicable to this issue. Add automated tests for deterministic core/validation behavior and manual evidence for desktop behavior. Record commit, pack hash when relevant, commands, observed results and untested scenarios. Do not close merely because the code builds.
