# Windows 11 v0.1 verification

Local distribution built from commit c4a45729fc5fcd0841a01a2f09b8a6199d89f9f2 with SDK 10.0.303. Windows 11 Pro build 22631, AMD Ryzen 9 7900X (24 logical processors), one 2560×1440 display at 96 DPI. See [shell proof results](C03_VERIFICATION.md) and the [full verification matrix](TESTING.md).

| Check | Observed result |
| --- | --- |
| Locked build, tests and import | Release build passed with 0 warnings and 0 errors. Seven xUnit cases passed. All 102 imported PNG hashes and 80 mappings matched. |
| Shipped pack | PackTool validated 71 sprites, 47 recipes and 8 sounds. All retained sprite IDs occur in recipes. Nine source frames are excluded with reasons in the audit. |
| Editing guide | Applying the six guide changes to a copy yielded a valid pack with 48 recipes and nine usable sound entries. |
| Desktop shell | Tobby observed body click reactions, preserved typing focus during clicks, drag and floor drop, and the corrected arrow cursor. Win32 hit testing resolved the body to Cutsy and a zero-alpha corner to a separate process in the C03 build. Tobby later observed the shipped walk animation. |
| Standalone | Self-contained Cutsy.exe displayed the mascot. The second process exited and the first opened Settings. The launch passed with DOTNET_ROOT and DOTNET_ROOT_X64 pointing at an empty test location. A fresh Windows account without .NET was unavailable. The extraction location was not confirmed. |
| Portable ZIP | Extracted to a separate folder. The executable used the adjacent 120 px setting, and the displayed frame measured 121 physical pixels including its padding. A separate run with Gaming mode enabled and automatic fullscreen hiding disabled kept the mascot hidden. A malformed override JSON at startup fell back to the embedded pack and displayed the mascot. |
| Short performance sample | Standalone default pack, 12 seconds of ordinary activity. Process CPU time divided by elapsed time and 24 logical processors was 0.0054% of machine capacity. End working set was 143.9 MiB (about 151 MB), with 372 handles. The sample is close to the memory target and is not a separate idle/moving qualification or soak. |

The focused smoke pass leaves mixed-DPI and monitor removal, exact drag threshold and capture-loss scenarios, real window edge tracking and clipping, fullscreen video/presentation/lock and resume, audible playback and device changes, live bad-reload rollback, startup and read-only storage, and the two-hour soak unverified. The full runtime recipes passed validation, while smoother walk cycles remain a [deferred art follow-up](https://github.com/TobbyTravel/cutsy/issues/23).
