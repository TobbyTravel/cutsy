# Cutsy for Windows 11 x64

- **Standalone.** Open Cutsy.exe. It uses the embedded default pack and keeps preferences in your local application data.
- **Portable and editable.** Extract the complete ZIP into a writable folder and open Cutsy.exe from there. Keep portable.flag and the pack folder beside it. The extracted folder holds preferences and edited assets.
- **Controls.** Right-click Cutsy or her tray icon for Pause, Stay here, Mute, Size, Gaming mode, Settings, Recover position and Quit. Drag her by the body. She lands on an exposed window top or the desktop floor. Double-click the executable again to open settings for the running instance.
- **Edit.** Use Settings → Pack and preview to open the pack folder, reload a saved edit, and preview a recipe or sound. See PACK_EDITING.md for examples. Remove or rename the override pack to return to the embedded copy.
- **Volume and fullscreen.** The default volume is 10%. Cutsy hides during fullscreen activity, presentation or lock, and waits three seconds after the desktop is eligible again. Gaming mode offers manual control.

The executable includes the .NET desktop runtime. The .NET bundle can use a temporary per-user cache for native libraries, including in portable mode. The build is unsigned. See SHA256SUMS.txt alongside the distributed files for their checksums. This is a private project and its assets are for authorized users.
