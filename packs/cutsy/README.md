# Default mascot pack

sprites/ contains all 80 individually extracted RGBA PNGs ready for loading/inspection. It is not yet a validated runtime pack: C02 corrects art metadata and C04/C06 add pack.json, behaviors.json, masks and complete recipes; C08 adds WAV effects.

Read ../../docs/ASSET_AUDIT.md before using legacy names or sequence suggestions. Source hashes and original mappings are in ../../assets/source/provenance.json. No external download is necessary.
